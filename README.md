### How I approach problems

- **Calculate, don't guess.** If a number decides where hardware goes or what gets ordered, the software should work it out, not a person eyeballing it.
- **Design for bad signal.** Farms, warehouses and basements drop connection. Save locally first, sync when you can, and never lose what someone typed.
- **Put boundaries where they can't be skipped.** Tenant separation belongs in the database, not only in an `if` statement in the API.
- **One source of truth.** One client record, one identity, one scene model. Most bugs I've fixed came from two copies of the same data drifting apart.
